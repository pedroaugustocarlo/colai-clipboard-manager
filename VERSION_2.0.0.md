# Resumo das implementações versão **2.0.0**

## 1. Reordenação de itens (setas ↑/↓)

Cada item da lista tem setas empilhadas para subir ou descer uma posição.

## 2. Nome para os itens

Cada item tem um botão **Renomear**, que abre uma caixa de edição direto no card.

### Identificação visual

- Itens com nome exibem um **ícone de etiqueta laranja** antes do nome.
